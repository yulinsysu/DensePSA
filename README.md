## DensePSA

## Introduction
This repository is the official PyTorch implementation of DensePSA: Robust image watermarking framework with cross-scale dense structure and patch-wise self-attention mechanism. The paper proposes a deep image watermarking framework with cross-scale dense connection and self-attention mechanism.

## Train
If you need to train DensePSA, you should use commond line as following.

      python train.py
Requirements: torch  torchvision  kornia

## Test
The pre-trained model of DensePSA is avaliable at the pretrain floder. You can test it by command line as following.

      python test.py
